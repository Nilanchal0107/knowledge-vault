# Queue

A **Queue** is a linear data structure that follows the **FIFO (First In First Out)** principle.

This means the **first element inserted is the first element removed**.

### Real World Example

A queue works exactly like a **line at a ticket counter**:

```
Front -> Person1 -> Person2 -> Person3 -> Rear
```

* Person1 gets served first.
* New people join at the rear.

---

# Queue Operations

| Operation   | Description                      |
| ----------- | -------------------------------- |
| **Enqueue** | Insert an element at the rear    |
| **Dequeue** | Remove an element from the front |
| **isEmpty** | Check if the queue is empty      |
| **Size**    | Returns number of elements       |

---

# FIFO Principle

Example:

```
Insert: 10, 20, 30
```

Queue structure:

```
Front -> 10 -> 20 -> 30 <- Rear
```

Removing elements:

```
Dequeue -> 10
Dequeue -> 20
Dequeue -> 30
```

---

# Queue Implementation Logic

In lower-level languages such as **C, C++, and Java**, queues are often implemented using **arrays** with two pointers:

```
front
rear
```

### Initialization

```
front = -1
rear = -1
```

### First Insertion

```
front = 0
rear = 0
```

### Enqueue Operation

```
rear = rear + 1
array[rear] = value
```

### Dequeue Operation

```
front = front + 1
```

---

# Queue Implementation in Python

Python simplifies queue implementation using **lists**.

### Python Implementation

```python
class Queue:

    def __init__(self):
        self.items = []

    def is_empty(self):
        return len(self.items) == 0

    def enqueue(self, value):
        self.items.append(value)

    def dequeue(self):
        if self.is_empty():
            raise Exception("Queue is empty")
        return self.items.pop(0)
```

---

# Example Usage

```python
q = Queue()

q.enqueue(10)
q.enqueue(20)
q.enqueue(30)

print(q.dequeue())
print(q.dequeue())
print(q.dequeue())
```

### Output

```
10
20
30
```

---

# Time Complexity

| Operation | Complexity |
| --------- | ---------- |
| Enqueue   | O(1)       |
| Dequeue   | O(n)       |

The `dequeue` operation takes **O(n)** time because elements shift in Python lists.

For production systems, Python provides an optimized structure:

```
collections.deque
```

# Deque (Double Ended Queue)

A **Deque** allows insertion and deletion from **both ends** of the queue.

```
Front <----> Rear
```

### Allowed Operations

| Operation         | Description |
| ----------------- | ----------- |
| Insert at front   |             |
| Insert at rear    |             |
| Delete from front |             |
| Delete from rear  |             |

However, **access from the middle is not allowed**.

---

# Deque Example

Operations:

```
Insert rear → 10
Insert front → 20
Insert rear → 30
Insert rear → 40
Insert front → 50
```

Structure becomes:

```
50 20 10 30 40
```

---

# Deque Implementation in Python

```python
class Deque:

    def __init__(self):
        self.items = []

    def is_empty(self):
        return len(self.items) == 0

    def insert_front(self, value):
        self.items.insert(0, value)

    def insert_rear(self, value):
        self.items.append(value)

    def delete_front(self):
        if self.is_empty():
            raise Exception("Deque is empty")
        return self.items.pop(0)

    def delete_rear(self):
        if self.is_empty():
            raise Exception("Deque is empty")
        return self.items.pop()
```

---

# Example Usage

```python
dq = Deque()

dq.insert_rear(10)
dq.insert_front(20)
dq.insert_rear(30)
dq.insert_rear(40)
dq.insert_front(50)

print(dq.delete_rear())
print(dq.delete_rear())
print(dq.delete_front())
print(dq.delete_front())
print(dq.delete_rear())
```

### Output

```
40
30
50
20
10
```

# Key Differences

| Feature   | Stack | Queue | Deque        |
| --------- | ----- | ----- | ------------ |
| Principle | LIFO  | FIFO  | Both         |
| Insert    | Top   | Rear  | Front / Rear |
| Delete    | Top   | Front | Front / Rear |

# Key Takeaways

* **Queue follows FIFO principle**
* **Insertion happens at rear**
* **Deletion happens at front**
* **Deque allows operations from both ends**
* Python lists simplify implementation but may not be optimal for large-scale systems
