📚 Data Structures & Algorithms Notes (Python)
1. What is Data?

Data = Raw information used by programs.

Examples:

Numbers

Names

User records

Inputs to a program

Example in Python:

a = 5
b = 10
print(a + b)

Here 5 and 10 are data.

2. What is a Data Structure?

A Data Structure is a way to store and organize data in memory so it can be accessed efficiently.

Think of it like containers for storing things.

Example analogy:

Data	Container
Water	Bottle / Bucket / Glass

Similarly in programming:

Data Structure	Purpose
Array/List	Store sequential data
Linked List	Dynamic storage
Stack	LIFO operations
Queue	FIFO operations
Tree	Hierarchical data
Graph	Network relationships

Example in Python:

arr = [10, 20, 30, 40]

Here the list acts as a data structure.

3. What is an Algorithm?

An Algorithm is a step-by-step procedure to solve a problem.

Example: Algorithm to make tea

Boil water

Add tea leaves

Add milk

Add sugar

Serve

Similarly in programming:

def add_numbers(a, b):
    return a + b

This is an algorithm to add two numbers.

4. Why Do We Need Time Complexity?

Two programs may solve the same problem but one may run faster.

Example:

Program A → takes 1 second
Program B → takes 10 seconds

We prefer Program A.

So we need a way to measure efficiency.

This is called:

⏱ Time Complexity

Time complexity measures how runtime increases as input size increases.

Input size is represented by:

n

Example:

If input size increases from:

10 → 100 → 1000

We check how the program time grows.

5. Rules of Time Complexity
Rule 1 — Ignore Constants

Example:

2n + 5

Becomes:

O(n)

Because constants do not matter for large inputs.

Rule 2 — Focus on Dominant Term

Example:

n² + n + 5

Dominant term:

n²

Final complexity:

O(n²)
6. Order of Time Complexity (Best → Worst)
O(1)       Constant
O(log n)   Logarithmic
O(n)       Linear
O(n log n)
O(n²)      Quadratic
O(n³)      Cubic
O(2^n)     Exponential

Better algorithms have smaller growth rates.

7. Types of Time Complexity Analysis
1️⃣ Best Case — Ω (Omega)

Minimum time required.

Example:

Searching first element.

2️⃣ Average Case — Θ (Theta)

Expected runtime.

3️⃣ Worst Case — O (Big O)

Maximum time required.

Most commonly used in interviews.

8. Constant Time Complexity — O(1)

Time does not depend on input size.

Example:

x = 5
print(x)

Execution time stays same regardless of input.

Characteristics:

No loops

No recursion

Only fixed operations

9. Linear Time Complexity — O(n)

When execution grows proportionally with input size.

Example:

for i in range(n):
    print(i)

If:

n = 10 → loop runs 10 times
n = 100 → loop runs 100 times

So complexity = O(n).

Multiple Independent Loops
for i in range(n):
    print(i)

for j in range(n):
    print(j)

Complexity:

O(n + n)

Ignore constants →

O(n)
10. Quadratic Time Complexity — O(n²)

Occurs when nested loops are used.

Example:

for i in range(n):
    for j in range(n):
        print(i, j)

If:

n = 5

Loop runs:

5 × 5 = 25 times

So complexity:

O(n²)
11. Cubic Time Complexity — O(n³)

Three nested loops.

Example:

for i in range(n):
    for j in range(n):
        for k in range(n):
            print(i, j, k)

Total operations:

n × n × n

Complexity:

O(n³)
12. Logarithmic Time Complexity — O(log n)

Occurs when input size reduces by a factor each iteration.

Example:

while n >= 1:
    print("Hello")
    n = n // 2

Example run:

n = 16

16 → 8 → 4 → 2 → 1

Iterations:

log₂(16) = 4

So complexity:

O(log n)
Doubling Case
i = 1

while i < n:
    print(i)
    i = i * 2

Example:

1 → 2 → 4 → 8 → 16

Also:

O(log n)
13. Quick Method to Identify Time Complexity
No loops
O(1)
One loop
O(n)
Two nested loops
O(n²)
Three nested loops
O(n³)
Divide by 2 every iteration
O(log n)
14. Dominant Term Rule

If a program contains:

O(1)
O(log n)
O(n)
O(n²)

Final complexity = largest one

O(n²)
15. Example
print(n)

for i in range(n):
    print("Hello")

for i in range(n):
    for j in range(n):
        print("Chai")

while n >= 1:
    print("DSA")
    n = n // 2

Complexities:

O(1)
O(n)
O(n²)
O(log n)

Final Answer:

O(n²)
🎯 Key Takeaways

✔ Ignore constants
✔ Focus on dominant term
✔ Nested loops multiply
✔ Sequential loops add
✔ Divide-by-2 loops → log n
