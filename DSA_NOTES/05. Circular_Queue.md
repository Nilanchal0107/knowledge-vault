# What is a Circular Queue

A **Circular Queue** is a linear data structure that follows the **FIFO (First In First Out)** principle, but the last position connects back to the first position.

This forms a **circular structure**.

```id="x4bh0g"
Front -> [1][2][3][4][5] <- Rear
            ↑         ↓
            └─────────┘
```

When the **rear reaches the last index**, it wraps around to the **first index**.

---

# Problem with Normal Queue

When implementing a queue using a **fixed-size array**, we face a memory wastage issue.

Example:

Initial Queue:

```id="ec8h1o"
[10][20][30][40][50]
 F              R
```

After deletions:

```id="19icso"
[  ][  ][30][40][50]
      F        R
```

Even though **two spaces are empty**, we cannot insert new elements because **rear is already at the last index**.

This results in **unused memory**.

---

# How Circular Queue Solves It

Circular Queue connects the **last index back to the first index**.

When the rear reaches the last position and there is space at the beginning, it **wraps around**.

Example:

```id="sh9t3r"
[60][  ][30][40][50]
  R     F
```

The queue behaves like a **cycle instead of a straight line**.

---

# Key Concepts

Circular Queue uses two pointers:

| Pointer   | Purpose                             |
| --------- | ----------------------------------- |
| **Front** | Points to the first element         |
| **Rear**  | Points to the last inserted element |

Initial values:

```id="sdg0nb"
front = -1
rear = -1
```

---

# Why Modulo Operator is Used

The **Modulo Operator (`%`)** ensures the index wraps around when it reaches the end.

Formula:

```id="np9qql"
index = (index + 1) % size
```

Example with size = 5:

```id="10g1u4"
0 → 1 → 2 → 3 → 4 → 0 → 1 → 2 ...
```

This allows the queue to behave **circularly**.

---

# Conditions for Empty and Full Queue

### Queue Empty

```id="pyz98a"
front == -1
```

---

### Queue Full

```id="u8t8lq"
(rear + 1) % size == front
```

This means the **next position of rear is front**, so no space is left.

# Circular Queue Implementation in Python

```python
class CircularQueue:

    def __init__(self, size):
        self.size = size
        self.items = [None] * size
        self.front = -1
        self.rear = -1

    def enqueue(self, value):

        if (self.rear + 1) % self.size == self.front:
            print("Queue is full")
            return

        if self.front == -1:
            self.front = 0
            self.rear = 0
        else:
            self.rear = (self.rear + 1) % self.size

        self.items[self.rear] = value

    def dequeue(self):

        if self.front == -1:
            print("Queue is empty")
            return

        value = self.items[self.front]

        if self.front == self.rear:
            self.front = -1
            self.rear = -1
        else:
            self.front = (self.front + 1) % self.size

        print(value)
```

# Example Usage

```python
cq = CircularQueue(5)

cq.enqueue(10)
cq.enqueue(20)
cq.enqueue(30)
cq.enqueue(40)
cq.enqueue(50)

cq.dequeue()
cq.enqueue(60)

cq.dequeue()
cq.dequeue()
cq.dequeue()

cq.dequeue()
```

# Key Takeaways

* Circular Queue solves **memory wastage in normal queues**
* Uses **modulo arithmetic to wrap indices**
* Requires **fixed-size memory**
* Maintains **FIFO order**
* Efficient for **buffer-based systems**
