# 📦 What is a Stack?

A **Stack** is a **linear data structure** that follows the **LIFO principle**.

> **LIFO = Last In First Out**

This means the **last element inserted is the first one removed**.

---

# 🔄 LIFO Principle

Example using **books stacked on a table**:

| Step        | Stack State         |
| ----------- | ------------------- |
| Push Book 1 | Book1               |
| Push Book 2 | Book2, Book1        |
| Push Book 3 | Book3, Book2, Book1 |

If we remove a book:

| Operation | Result              |
| --------- | ------------------- |
| Pop       | Book3 removed first |

Because it was the **last inserted**.

---

# 🌍 Real World Examples

Stacks are used in many applications:

| Use Case             | Explanation                      |
| -------------------- | -------------------------------- |
| Undo / Redo          | Editors maintain previous states |
| Browser History      | Back and forward navigation      |
| Function Calls       | Stored in **call stack**         |
| Recursion            | Uses stack internally            |
| Parentheses Matching | Used in compilers                |

---

# ❓ Why Use a Stack?

Even though we have **arrays or lists**, stacks restrict operations.

Normal lists allow:

* Access any index
* Insert anywhere
* Delete anywhere

Stacks restrict this to maintain **LIFO behavior**.

---

# ⚙️ Core Stack Operations

| Operation         | Description                       |
| ----------------- | --------------------------------- |
| **Push**          | Insert element into stack         |
| **Pop**           | Remove top element                |
| **Peek**          | View top element without removing |
| **isEmpty**       | Check if stack is empty           |
| **Length / Size** | Number of elements in stack       |

# 🧑‍💻 Stack Implementation in Python

We implement stack using a **Python list**.

### Create Stack Class

```python
class Stack:

    def __init__(self):
        self.s = []
```

---

## Length Function

Returns number of elements in stack.

```python
def length(self):
    return len(self.s)
```

---

## Push Operation

Insert element at **top of stack**.

Here top is **index 0**.

```python
def push(self, value):
    self.s.insert(0, value)
```

---

## Peek Operation

View top element without deleting.

```python
def peek(self):
    if len(self.s) == 0:
        raise Exception("Stack is Empty")
    else:
        return self.s[0]
```

---

## Pop Operation

Remove element from **top of stack**.

```python
def pop(self):
    if len(self.s) == 0:
        raise Exception("Stack is Empty")
    else:
        return self.s.pop(0)
```

---

# 🧪 Example Execution

```python
st = Stack()

st.push(10)
st.push(20)
st.push(30)

print(st.peek())   # 30

print(st.pop())    # 30
print(st.pop())    # 20
print(st.pop())    # 10
```

### Output

```
30
30
20
10
```

Explanation:

| Operation | Stack      |
| --------- | ---------- |
| Push 10   | [10]       |
| Push 20   | [20,10]    |
| Push 30   | [30,20,10] |
| Pop       | removes 30 |
| Pop       | removes 20 |
| Pop       | removes 10 |

---

# 🔁 Alternative Implementation (Append Method)

Instead of inserting at index **0**, we can insert at the **end**.

### Push

```python
def push(self, value):
    self.s.append(value)
```

### Pop

```python
def pop(self):
    return self.s.pop()
```

This method is **more common in Python**.

# 🎯 Key Takeaways

✔ Stack follows **LIFO principle**
✔ Only **top element** can be accessed
✔ Implemented using **lists or arrays**
✔ Core operations: **push, pop, peek**
✔ Python lists make stack implementation easy
✔ Stack is heavily used in **recursion and debugging**
